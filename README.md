# Neighborhood Dash

A map for finding U.S. census tracts that match the neighborhood you want: set preferences and limits, search a state, county, or metro, inspect the evidence behind each place, and compare a shortlist.

Live site: https://umqadir.github.io/neighborhood-dash/

This repository only publishes the prebuilt site. Each deploy is attached to a release and published by the Pages workflow. Data sources and attributions are listed in the site's "About & sources" panel.
